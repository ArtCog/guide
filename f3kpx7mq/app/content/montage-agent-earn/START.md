# Старт: монтаж и моушен-графика через агента

Этот файл отдаётся агенту. Положи его в пустую папку, открой в ней Claude Code (или Codex) и напиши:

> Прочитай START.md и проведи меня по шагам. Где написано СПРОСИ, спроси меня.

За 20-40 минут у тебя будет: движок моушен-графики, официальные скиллы к нему, монтаж живой
съёмки, первый ролик в твоих цветах и заготовка обвязки (стиль, антислоп, уроки).

---

## Для агента: как работать по этому файлу

- Иди по шагам. После каждого шага коротко отчитайся: что поставил, что проверил, что дальше.
- Определи ОС сам (Windows, macOS, Linux) и бери команды под неё.
- Ничего не удаляй и не перезаписывай без спроса. API-ключи не печатай в чат, не коммить, держи в `.env`.
- Команды вида `/plugin ...` пользователь вводит сам в окне Claude Code. Если они понадобятся, выпиши их в конце.
- Рендер с кодом 0 ещё не значит, что ролик получился: в Remotion пустой кадр рендерится «успешно».
  Проверяй результат стоп-кадрами и показывай их пользователю.

Проверь версии и доустанови недостающее:

|---|---|---|---|

## Шаг 1. Моушен-графика: Remotion

Remotion делает видео из кода (React). Агент пишет сцены, ты смотришь их в браузере, потом рендер в MP4.

```bash
npx create-video --yes --blank my-video
cd my-video
npx remotion skills add
npm run dev
```

- `npx remotion skills add` ставит официальные скиллы Remotion для агента. Главный вход: `/remotion-best-practices`.
- `npm run dev` открывает Remotion Studio в браузере: там видно каждую сцену покадрово.
- Агента запускай во втором терминале в папке `my-video`.

Лицензия Remotion (проверено 17.10.2026 по `LICENSE.md` и remotion.pro):
бесплатно для частного лица и для компании до 3 сотрудников, включая коммерческие заказы.
Компании больше нужна Company License ($25 в месяц за место).

## Шаг 2. Свой стиль до первого ролика

СПРОСИ пользователя:
1. Для чего первый ролик (канал, заказчик, продукт)?
2. Цвета: 2-3 HEX-кода или ссылка на сайт/бренд, с которого их взять.
3. Шрифт (если не знает, предложи 2 варианта из Google Fonts с кириллицей).
4. 2-3 ролика или кадра, которые ему нравятся (ссылки или скриншоты).

Создай в корне проекта `STYLE.md`:

```markdown
# Стиль

## Цвета
фон: #......   текст: #......   акцент: #......  (акцент только на главном слове или объекте)

## Шрифты
заголовки: ...   текст: ...   минимальный размер на вертикальном видео: 48 px

## Движение
- объекты появляются из причины (их что-то толкает, открывает, вызывает), не из ниоткуда
- пружины без лишнего дребезга; уход быстрее появления
- одна главная вещь в кадре в каждый момент

## Нельзя
- (пополняется после каждой правки, см. SLOP.md)
```

Если пользователь дал сайт или бренд, можно взять готовый `DESIGN.md` из
github.com/VoltAgent/awesome-design-md и перенести из него палитру и шрифты в `STYLE.md`.

## Шаг 3. Первый ролик

Сначала план, потом код. Пришли пользователю план в словах:
сцены по секундам, что на экране, что движется и почему. Код пиши только после его «да».

Задание для первого ролика (подставь ответы из шага 2):

> Сделай 10-секундную заставку 1920x1080, 30 fps: название «...» и подзаголовок «...».
> Строго по STYLE.md. Сначала план по секундам, жди моего «да».
> Потом отрендери по одному стоп-кадру на каждую сцену (`npx remotion still`) и покажи мне.
> Финальный рендер в MP4 только после моего «да» по кадрам.

Каждую правку пользователя записывай одной строкой в `LESSONS.md`: было → стало → почему.

## Шаг 4. Монтаж живой съёмки (по желанию)

Выбери вместе с пользователем один вариант.

**A. video-use** (browser-use, MIT). Кладёшь сырые дубли в папку, агент режет слова-паразиты,
фальстарты и паузы по транскрипту с таймингом слов, делает цвет, субтитры, плавные склейки звука.
Нужен ключ ElevenLabs для распознавания речи (по их прайсу $0.22 за час звука).
Установка: попроси себя же, агента, выполнить «Set up https://github.com/browser-use/video-use for me».
Ключ пользователь вставляет сам в `.env` (`ELEVENLABS_API_KEY=...`).

**B. ChatMonteur** (MIT, бесплатно и локально: распознавание faster-whisper на твоём компьютере).
Монтаж говорящей головы по смыслу, субтитры, графика, звук.

```bash
git clone https://github.com/ArtCog/chatmonteur
cd chatmonteur
./setup.ps1        # Windows (macOS/Linux: ./setup.sh)
chatmonteur edit raw.mp4 --project my-first-edit
```

## Шаг 5. Обвязка: чтобы агент рос, а не начинал с нуля

Создай три файла и указатель на них:

- `STYLE.md` уже есть (шаг 2).
- `SLOP.md`: список того, что выглядит дёшево и запрещено. Начни с 5 пунктов, например:
  текст, прилетающий со всех сторон сразу; бесконечное покачивание объектов без причины;
  переходы-шаблоны (вспышка, «киноплёнка»); мелкий текст; три акцентных цвета в одном кадре.
- `LESSONS.md`: уроки из правок пользователя (пополняется после каждого ролика).
- `CLAUDE.md` (для Codex `AGENTS.md`):

```markdown
Перед любой работой с видео прочитай STYLE.md, SLOP.md и LESSONS.md.
Порядок всегда: план словами → «да» → стоп-кадры → «да» → рендер.
После правки пользователя добавь урок в LESSONS.md.
```

Следующий уровень, когда наберётся 3-5 роликов: вынести повторяющийся процесс в свой скилл
(папка `.claude/skills/<имя>/SKILL.md` с полями `name` и `description` в шапке) и поставить хуки,
которые не дают пропустить проверку (например, не рендерить без стоп-кадров).

## План на первую неделю

СПРОСИ пользователя, чего он хочет: брать заказы, продавать систему экспертам или делать контент для себя.
Подстрой план под ответ.

**День 1.** Всё по этому файлу: установка, стиль, первый ролик в своих цветах.

**Дни 2-4.** Три демо под одну нишу, каждое по PROMPTS.md: рилс эксперта (3.2), ролик-запуск продукта (3.3),
интро и плашки канала (3.5). После каждого пользователь правит, ты пишешь уроки в LESSONS.md.

**Дни 5-7.**
- Если цель заказы: найти 3-5 блогеров или стартапов, которых пользователь знает, сделать по одному ролику
  под каждого (их цвета, их тема) и помочь написать короткое сообщение. Готовый пример под человека продаёт
  лучше любого портфолио.
- Если цель продавать систему: собрать из трёх демо пакет для одного эксперта (STYLE.md в его цветах,
  SLOP.md, 3 шаблона сцен, короткая инструкция) и показать ему, как он делает ролик сам.
- Если цель контент для себя: снять и смонтировать три своих ролика и после каждого пополнить LESSONS.md.
