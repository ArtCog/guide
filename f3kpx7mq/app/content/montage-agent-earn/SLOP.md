# Антислоп для моушен-графики

Слоп это облик, который любой агент выдаёт по умолчанию и который зритель видит в каждом втором ролике.
Этот список собран на реальных роликах: каждый пункт однажды испортил кадр, и его пришлось переделывать.

Как пользоваться: положи файл в корень проекта рядом со `STYLE.md` и скажи агенту
«перед планом и перед показом кадров сверяйся с SLOP.md». Новое, что тебе не понравилось, дописывай сюда же
одной строкой: что не делаем → как надо.

---

## Раскадровка

1. **Сцены без связи.** Под каждую мысль своя новая картинка, графика не вырастает из предыдущей.
   → Один мир на весь ролик, новое вырастает из старого.
2. **Перегрузка.** Много вещей, кнопок и надписей сразу, главный объект обвешан деталями.
   → Одна главная вещь в кадре в каждый момент.

## Камера

3. **Камера дёргается.** Встаёт на каждом слове, топчется перед движением, въезжает и выезжает ради одного слова.
   → Проходит ключевые точки плавно, к большому ходу одно решительное движение.

## Движение

4. **Движение без причины и против физики.** Вещь появляется сама по себе, зависает в полёте, бесконечно
   покачивается без повода.
   → У каждого движения есть причина в кадре, у вещей есть вес и инерция.
5. **Персонаж без веса.** Прыжок висит в воздухе и плывёт вниз, приземление без приседа.
   → Полёт по дуге, присед перед прыжком и после приземления.
6. **Курсор мечется.** Жмёт на ходу, останавливается на одном, а выбранным оказывается другое.
   → Пришёл, остановился, нажал, подождал, ушёл.

## Смены и переходы

7. **Один переход на весь ролик.** Одинаковый свайп или резкое перелистывание между всеми сценами.
   → Переходы разные по виду и направлению, резкая склейка только там, где она служит смыслу.
8. **Шаблонные переходы.** Вспышка, «киноплёнка», засветка, кручёное приближение из набора эффектов.
   → Переход делает сама вещь: открывается, уезжает, превращается.
9. **Вещь из ниоткуда, старое не убрано.** Новое возникает рядом, старое остаётся висеть, вход через «сжатие».
   → Новое выходит из старого, содержимое переходит, ушедшее уходит целиком.
10. **Смена через «призрак».** Между двумя состояниями видна просвечивающая смесь цветов или каша из букв.
    → Состояние меняется действием: нажатием, прокруткой, уходом за край.
11. **Скачок размера на стыке сцен.** На переходе вещь на один кадр меняет размер.
    → Новая сцена начинается с того же размера на экране, на котором закончилась старая.

## Кадр и текст

12. **Вёрстка на глаз.** Ряды не до края, строки одной фразы вразнобой, значок не читается на своём фоне.
    → Ряды от края до края, строки фразы в одном строю, значки контрастны фону.
13. **Подписи для порядка.** Надпись повторяет то, что и так видно, или висит просто чтобы было.
    → Надпись появляется только там, где картинка молчит.
14. **Текст со всех сторон.** Слова прилетают одновременно с разных направлений.
    → Текст появляется по одному смысловому куску, откуда-то по причине.
15. **Мелкий текст.** Подписи, которые на телефоне не прочитать.
    → На вертикальном видео не мельче 48 px, лучше крупнее.
16. **Радуга акцентов.** Три и больше акцентных цвета в одном кадре.
    → Один акцентный цвет на главном слове или объекте.

---

## Проверка перед показом заказчику

- Пройди по стоп-кадрам каждой сцены и по полоске кадров на каждом переходе.
- На каждый пункт выше ответь «нет такого». Нашёл, значит исправь, потом показывай.
- Рендер с кодом 0 не значит, что кадр хороший: смотри картинку, а не лог.
