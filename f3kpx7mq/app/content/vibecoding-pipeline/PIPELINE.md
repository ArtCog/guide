# PIPELINE: шпаргалка по скиллам Мэтта Покока

Источник: github.com/mattpocock/skills (MIT), скилл `ask-matt` (карта всех скиллов автора).
В Claude Code перед именем ставится приставка: `/mattpocock-skills:grill-me`. Команда должна стоять
первой в сообщении.

## Основной путь: идея → готовая вещь

| Шаг | Команда | Когда | Что на выходе | Можно пропустить |
|---|---|---|---|---|
| 0 | `/setup-matt-pocock-skills` | один раз на проект | где хранятся задачи, куда класть доки | нет |
| 1 | `/grill-with-docs` | в папке проекта, перед любой правкой | общее понимание + словарь проекта и записи решений | нет |
| 1 | `/grill-me` | папки проекта нет (план, текст, решение) | общее понимание, без файлов | нет |
| 1½ | `/prototype` | вопрос не решить словами (экран, логика) | черновой вариант, на который смотришь | если всё ясно на словах |
| 2 | `/to-spec` | работа больше одной сессии | ТЗ: проблема, решение, истории пользователей, тесты, что НЕ делаем | задача на вечер |
| 3 | `/to-tickets` | после `/to-spec` | тикеты: сквозные куски, у каждого «что закрыть до него» | задача на вечер |
| 4 | `/implement` | по одному тикету, между ними `/clear` | код через тесты, проверки, коммит | нет |
| 4 | `/implement-spec` | хочешь собрать всё ТЗ разом | параллельные исполнители, одна ветка | если идёшь по тикетам руками |
| 5 | `/code-review` | сам внутри `/implement`; отдельно для ветки или PR | два отчёта: правила проекта и соответствие ТЗ | нет |
| 6 | `/retro` | после сборки, до `/clear` | правки обвязки агента: подсказки, правила, проверки | если сессия прошла гладко |

## Короткий путь (задача на вечер)

`/grill-with-docs` (или `/grill-me`) → `/implement` в том же окне.

## Правила контекста

- Шаги 1-3 в одном непрерывном окне. Не сжимать до конца `/to-tickets`.
- Перед каждым тикетом `/clear`.
- Окно подходит к пределу раньше времени: `/precompact`, потом `/compact` на ближайшей границе шагов.
  `/precompact` (скилл автора канала, `claude plugin install precompact@artcog` после
  `claude plugin marketplace add ArtCog/skills`) записывает то, что сжатие теряет: тупики, твои решения,
  точное место остановки. Хук возвращает записку сразу после сжатия.
- Работа переезжает в новую папку, к другому агенту или человеку: `/handoff`, файл передачи для новой сессии.
- Почему: чем длиннее вход, тем менее надёжно отвечает модель (Chroma, «Context Rot», 18 моделей, июль 2025).

## Рядом с основным путём

| Ситуация | Команда |
|---|---|
| Огромный туманный проект, не помещается в одну сессию | `/wayfinder` → потом `/to-spec` |
| Что-то сломалось и не чинится с наскока | `/diagnosing-bugs` |
| Копятся чужие баг-репорты и запросы | `/triage` |
| Нужно передать работу в другую папку, агенту или человеку | `/handoff` |
| Контекст кончается посреди работы | `/precompact` → `/compact` |
| Агент сказал непонятно | `/wait-what` |
| Нужна информация от другого человека | `/to-questionnaire` |
| Шаги, которые может сделать только человек (ключи, панели сервисов) | `/wizard` |
| Не помнишь, какой скилл под ситуацию | `/ask-matt` |
