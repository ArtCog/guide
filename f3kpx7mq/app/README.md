# Knowledge base app

A static page that is both the Telegram Mini App of @imersivnybot and a normal website:
`https://artcog.github.io/guide/f3kpx7mq/app/`. No build step, no framework, no server.

| File | What it is |
|---|---|
| `index.html`, `app.css`, `app.js` | the app (hash routes `#/` home, `#/t/guides`, `#/t/skills`, `#/t/inspo` tabs, `#/m/<slug>`, `#/m/<slug>/<file>`; old `#/s/<section>` links show `#/`, `#/t/more` shows «Гайды») |
| `content/site.json` | sections (only validated and kept for the record, no longer shown), course line, channel links, public base URL, bot name; `bioPin`: the slug the Instagram bio link `?startapp=new` opens instead of the newest guide (empty: the newest; Arthur, 2026-11-05) |
| `content/<slug>/meta.json` | one material; its files sit next to it |
| `content/index.json` | generated by `build_index.py`, never edit by hand |
| `pin_post.py` | after `build_index.py`: writes the channel's pinned post (10 newest guides from videos, last line «Все гайды» → `startapp=guides`) to `Distribution/telegram/posts/pinned-guides/post-latest.txt` |
| `vendor/` | Phosphor icons 2.1.1 and marked 18.0.13, both MIT, licences next to them |

## Home page and tabs (Arthur, 2026-11-20, look F «тёплая бумага»)

A viewer comes from a Reel (Instagram, TikTok) or a YouTube video through the channel's pinned post and must find the
guide to that video at once. Four tabs in a glass bar at the bottom:

- **Главная** (`#/`, also `startapp` with no slug): the newest guide or skill as a big card with its cover, the course
  card (`site.json` `course`, now «Скоро»), «Недавние» (the next four) as a 2×2 grid and «Все гайды · N» to the tab.
- **Гайды** (`#/t/guides`, `startapp=guides`): step-by-step guides, `kind: guides`, newest first, 10 and «Показать ещё».
- **Скиллы и плагины** (`#/t/skills`, `startapp=skills`; «Скиллы» in the bar): `kind: skills`, what is downloaded and
  installed as a skill or plugin. A step-by-step PDF guide stays in «Гайды» even when it installs skills.
- **Вдохновение** (`#/t/inspo`, `startapp=inspo`): sites, `kind: inspo`.

A list shows the name as the video said it (`pinTitle`, else the title before its colon), the kind and date, two lines
of the summary. The cover is the material's own `cover.jpg` (16:10: a guide's PDF spread, a site's screenshot) whole in a
16:10 frame, not zoomed (Arthur, 2026-11-20); without a cover the frame shows the file icon and the kind. «Назад» goes to
the tab the material was opened from; opened by a link, to its own tab. `startapp=<slug>` opens a material,
`startapp=new` the newest guide from a video (or `bioPin`), `startapp=preview` shows held materials too. The viewer-facing
words are «база знаний» for the app and «гайд» for a material (not «материал»).

## Add a material

1. Create `content/<slug>/` (lowercase latin, digits, hyphens) with `meta.json` and the files.
2. Run `C:\Users\magme\AppData\Local\Programs\Python\Python313\python.exe build_index.py`. It refuses to write the
   index and lists the problems if something is off (unknown section or type, bad date, missing file, long dash).
3. Commit, then push to `main` (GitHub Pages deploys in 30-90 s). Check with `curl -sI ".../content/index.json?cb=$RANDOM"`.

The post links to the material as `https://t.me/imersivnybot?startapp=<slug>`.

**Material for a post that is not out yet** (Arthur, 2026-10-17: materials appear only when the post goes out):
push it ahead with `publishAt` = the post's time, or `draft: true` while the time is unknown. A held material is in
no list, but its startapp link opens it, so Arthur can check it on his phone first and the post
link works from its first second. When the post is out, add `post_url` and push again.

## meta.json

| Field | Needed | Meaning |
|---|---|---|
| `title`, `summary` | yes | Russian, no long dashes |
| `section` | yes | an id from `site.json` (validated, not shown) |
| `type` | yes | гайд, скилл, статья, сайт, промпты, подборка, установщик |
| `kind` | no | the tab: `guides`, `skills` or `inspo` (sites only). Missing: from `type` (сайт → inspo, скилл → skills, else guides); set it when they differ, e.g. a START.md that installs a plugin is `skills` |
| `date` | yes | `YYYY-MM-DD`; newest first |
| `fromVideo` | no | `true`: a guide to a Reel or YouTube video: in the pinned post and the bio link `startapp=new` |
| `new`, `clip` | no | no effect since 2026-11-20 (the «Новое» carousel is gone); kept in old metas |
| `publishAt` | no | moment the post goes out, Berlin time with offset (`2026-10-18T10:00+02:00`); until then the material is in no list, from then on it appears by itself, no new push |
| `draft` | no | `true`: in no list until the field is removed and pushed (post time not known yet) |
| `files[]` | no | `name`, `about`, optional `url` (relative to this folder's app root, for files kept elsewhere on the site); `.md`/`.txt` open in the reader and can be copied |
| `agentFile` | no | one of `files`: the line «Прочитай `public url` и проведи меня по шагам» is offered for Claude Code |
| `agent` | no | own line for the agent instead (install commands) |
| `github` | no | `https://github.com/...` of the original; a «GitHub» row on the material page and a chip on its card |
| `quick` | no | «Быстрая установка» row: the quickest way in one or two sentences (Russian, no long dashes) |
| `note` | no | fine print under the rows, e.g. «Материал образовательный…» for money topics |
| `url` | sites | `https://` address; `domain` is derived |
| `post_url` | no | link to the Telegram post |
| `tags[]` | no | kept for a later search |
| `cover.jpg` | no | a file in the folder, picked up automatically, 16:10 (a guide's PDF spread 1280x800, a site's screenshot 800x500); shown whole in lists and big on the material page |

## Subscribers only (2026-10-17)

The app opens only for subscribers of the channel «ИИмерсивный» (id -1003695481859). `app.js` posts Telegram's
signed `initData` to `https://hermes-srv.tail7ba1c3.ts.net:8443/kb/access` (`ACCESS_URL` in `app.js`; Tailscale Funnel since 2026-11-06, before that Caddy → systemd `kb-access` on Hermes, source
`Distribution/mini-app/server/`). The server checks the signature with @imersivnybot's token and asks Telegram
`getChatMember`; @imersivnybot must be an administrator of the channel for that. Subscriber: a toast «Ты подписан на
канал, всё открыто». Not subscribed: a screen with «Подписаться на канал» and «Я подписался». Outside Telegram: a
screen with «Открыть в Telegram» (the same startapp link). If the check fails (server or Telegram down, bot not an
admin) the base stays open. localhost always sees everything. The files themselves stay reachable by their URLs:
this is a gate for the app, not protection of the files.

## Inside Telegram

`ready()`, `expand()`, always the app's own light page (header and background painted in `--page`, the warm paper `#f4efe7`; Arthur 2026-10-17 and 2026-11-20), Telegram's Back
button instead of the in-page one, downloads through `downloadFile` (Bot API 8.0, otherwise `openLink`), sharing
through `t.me/share/url`, `start_param` opens a material (routing only, nothing trusted). The Telegram script has no
integrity hash on purpose: Telegram updates it in place.

`pinTitle` (optional, guides from videos): the name as the video says it, no colon ("Graphify, карта проекта для Claude Code"). The lists show it as the material's name and `pin_post.py` uses it for the pinned post line; without it both take the title before its colon.
