# Knowledge base app

A static page that is both the Telegram Mini App of @imersivnybot and a normal website:
`https://guide.arturx.art/f3kpx7mq/app/`. No build step, no framework, no server.

| File | What it is |
|---|---|
| `index.html`, `app.css`, `app.js` | the app (hash routes `#/`, `#/s/<section>`, `#/m/<slug>`, `#/m/<slug>/<file>`) |
| `content/site.json` | sections, course line, channel links, public base URL, bot name, days a material counts as new |
| `content/<slug>/meta.json` | one material; its files sit next to it |
| `content/index.json` | generated by `build_index.py`, never edit by hand |
| `vendor/` | Phosphor icons 2.1.1 and marked 18.0.13, both MIT, licences next to them |

## Add a material

1. Create `content/<slug>/` (lowercase latin, digits, hyphens) with `meta.json` and the files.
2. Run `C:\Users\magme\AppData\Local\Programs\Python\Python313\python.exe build_index.py`. It refuses to write the
   index and lists the problems if something is off (unknown section or type, bad date, missing file, long dash).
3. Commit, then push to `main` (GitHub Pages deploys in 30-90 s). Check with `curl -sI ".../content/index.json?cb=$RANDOM"`.

The post links to the material as `https://t.me/imersivnybot?startapp=<slug>`.

**Material for a post that is not out yet** (Arthur, 2026-10-17: materials appear only when the post goes out):
push it ahead with `publishAt` = the post's time, or `draft: true` while the time is unknown. A held material is in
no list and not in «Новое», but its startapp link opens it, so Arthur can check it on his phone first and the post
link works from its first second. When the post is out, add `post_url` and push again.

## meta.json

| Field | Needed | Meaning |
|---|---|---|
| `title`, `summary` | yes | Russian, no long dashes |
| `section` | yes | an id from `site.json` |
| `type` | yes | гайд, скилл, статья, сайт, промпты, подборка, установщик |
| `date` | yes | `YYYY-MM-DD`; newest first |
| `new` | no | `true`/`false` forces the «Новое» carousel; otherwise new for `newDays` days after it appeared (`publishAt`, else `date`) |
| `publishAt` | no | moment the post goes out, Berlin time with offset (`2026-10-18T10:00+02:00`); until then the material is in no list, from then on it appears by itself, no new push |
| `draft` | no | `true`: in no list until the field is removed and pushed (post time not known yet) |
| `files[]` | no | `name`, `about`, optional `url` (relative to this folder's app root, for files kept elsewhere on the site); `.md`/`.txt` open in the reader and can be copied |
| `agentFile` | no | one of `files`: the line «Прочитай `public url` и проведи меня по шагам» is offered for Claude Code |
| `agent` | no | own line for the agent instead (install commands) |
| `url` | sites | `https://` address; `domain` is derived |
| `clip` | no | `{src, poster, still}` video for the «Новое» card (made in `C:\Projects\Distribution\mini-app\motion`) |
| `post_url` | no | link to the Telegram post |
| `tags[]` | no | kept for a later search |
| `cover.jpg` | no | a file in the folder, picked up automatically (site screenshots, 1280x800) |

## Subscribers only (2026-10-17)

The app opens only for subscribers of the channel «ИИмерсивный» (id -1003695481859). `app.js` posts Telegram's
signed `initData` to `https://n8n.arturx.art/kb/access` (Caddy → systemd `kb-access` on Hermes, source
`Distribution/mini-app/server/`). The server checks the signature with @imersivnybot's token and asks Telegram
`getChatMember`; @imersivnybot must be an administrator of the channel for that. Subscriber: a toast «Ты подписан на
канал, всё открыто». Not subscribed: a screen with «Подписаться на канал» and «Я подписался». Outside Telegram: a
screen with «Открыть в Telegram» (the same startapp link). If the check fails (server or Telegram down, bot not an
admin) the base stays open. localhost always sees everything. The files themselves stay reachable by their URLs:
this is a gate for the app, not protection of the files.

## Inside Telegram

`ready()`, `expand()`, always white (header and background painted white, Arthur 2026-10-17), Telegram's Back
button instead of the in-page one, downloads through `downloadFile` (Bot API 8.0, otherwise `openLink`), sharing
through `t.me/share/url`, `start_param` opens a material (routing only, nothing trusted). The Telegram script has no
integrity hash on purpose: Telegram updates it in place.
