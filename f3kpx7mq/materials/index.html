01 /grill-me — агент допрашивает тебя, пока план не станет крепким

Вместо того чтобы поддакивать твоему плану, агент задаёт по одному вопросу за раз и идёт по каждой ветке решений, пока не останется недоговорённостей. К каждому вопросу прикладывает свой рекомендуемый ответ — соглашайся одним словом или спорь. Работает не только про код: план ролика, структура бизнеса, выбор квартиры. Скилл Мэтта Покока — на английском, но пиши агенту по-русски, и допрос пойдёт по-русски.

Выбери, где ты работаешь:

Сайт claude.ai и приложение Claude на компьютере — шаги одинаковые.

  1. Скачай архив кнопкой внизу карточки. Не распаковывай — грузить надо именно .zip.
  2. Настройки → Capabilities → включи «Code execution and file creation». Без этого раздела «Skills» просто не будет.
  3. Настройки → Customize → Skills → кнопка «+» → «Create skill» → «Upload a skill» → выбери архив.

Готово. Слэш-команд в чате нет — просто напиши «поджарь меня» и свой план, скилл подхватится сам.

Способ первый — скопируй строку и отдай своему Claude Code:

Скачай https://guide.arturx.art/f3kpx7mq/claude-skills/grill-me-v1.1.zip,
распакуй папку grill-me в ~/.claude/skills/ и перезапустись

Способ второй — руками. Скачай архив и распакуй папку grill-me в:

Windows:      %USERPROFILE%\.claude\skills\
macOS/Linux:  ~/.claude/skills/

Перезапусти Claude Code → набери /grill-me. Или скажи словами: «поджарь меня».

Файл тот же, папка другая. Скачай архив и распакуй папку grill-me в:

~/.codex/skills/        — для всех проектов
.codex/skills/          — только для текущего проекта

SKILL.md — общий стандарт для агентов, поэтому один и тот же файл работает и в Claude Code, и в Codex без единой правки.

В ChatGPT скиллы тоже есть, и формат тот же.

  1. Скачай архив кнопкой внизу карточки, не распаковывая.
  2. Plugins → Skills → Create → «Upload from your computer» → выбери архив.

Нужен рабочий план
