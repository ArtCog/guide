    Anki Word Clipper — слова в Anki в один клик

    Бесплатное расширение для Chrome: выделяешь слово на любом сайте — и оно улетает в Anki готовой карточкой. С предложением-контекстом, переводом от ИИ, формами глагола, примером и озвучкой. Написано полностью искусственным интеллектом — как именно, смотри в видео на канале.

    Что оно умеет

    • Один клик — выделил слово → кнопка «+ Anki» → карточка в колоде. Не выходя со страницы.
    • Контекст — предложение, в котором встретилось слово, попадает на карточку автоматически (само слово подсвечено).
    • Перевод от ИИ по контексту — не «словарный» перевод, а значение именно в этом предложении (ИИ смотрит и на соседние предложения, чтобы не спутать Bank-банк с Bank-скамейкой). Плюс словарная форма: Häusern → das Haus, die Häuser.
    • Устойчивые выражения целиком — выделил weder → на карточке вся конструкция weder ... noch = «ни ... ни». Выделил предложение с идиомой → ИИ достанет из него именно идиому, а не первый попавшийся глагол.
    • Формы глагола — выделил ging → на карточке gehen (geht), ging, ist gegangen (три основные формы + 3-е лицо).
    • Разбор целого абзаца — выдели кусок текста → ИИ сам выберет 3–6 слов, стоящих изучения на твоём уровне → отметь галочками → все уходят карточками разом.
    • Уровень языка (A1–C2) — ИИ подстраивает перевод, синонимы и примеры под твой уровень.
    • 4 типа карточек — обычная (слово → перевод), двусторонняя, обратная (перевод → слово), cloze (пропуск слова в предложении).
    • Пример и синонимы — ИИ добавляет простое предложение-пример и 1–2 синонима попроще (опционально). Кнопка ↻ просит другой вариант перевода.
    • Озвучка — карточка произносит слово голосом системы (Anki TTS), без внешних сервисов.
    • 9 языков перевода и приватность — всё работает локально; наружу уходит только слово на перевод (и это отключается).

    Установка за 5 минут

    Шаг 1. Anki + AnkiConnect

    1. Установи Anki Desktop (бесплатно) и запусти его.
    2. В Anki: Tools → Add-ons → Get Add-ons… → вставь код 2055492159 → OK → перезапусти Anki.
    3. Anki должен быть запущен, когда пользуешься расширением.

    Шаг 2. Расширение в Chrome

    1. Скачай ZIP по кнопке выше и распакуй в постоянную папку (не удаляй её потом — Chrome загружает расширение прямо оттуда).
    2. Открой chrome://extensions → включи Режим разработчика (переключатель справа сверху).
    3. Нажми «Загрузить распакованное расширение» → выбери распакованную папку.

    Шаг 3. Разреши доступ

    1. Кликни иконку расширения (зелёная буква A на панели; если не видно — иконка-пазл → закрепить).
    2. Anki покажет окно «An application is attempting to access Anki» → жми Yes.
    3. В попапе появится «Anki подключён ✓». Готово — расширение само создаст нужные типы карточек.

    Как пользоваться

    • Одно слово: выдели → кнопка «+ Anki» → проверь перевод → Enter. Всё.
    • Целый абзац: выдели несколько предложений → «+ Anki» → откроется панель «разбор текста»: ИИ предложит слова для изучения, отметь нужные → «Добавить выбранные».
    • Тип карточки выбирается прямо в форме; тип по умолчанию — в попапе.
    • Кнопка ↻ у поля перевода — если вариант ИИ не понравился, получи другой.
    • ПКМ по выделению → «Добавить в Anki…» — запасной путь, работает даже там, где кнопка не появляется.
    • Хоткей Alt+A — открыть форму для текущего выделения.
    • Мгновенный режим (в попапе): клик добавляет карточку сразу, без формы. Shift+клик делает наоборот.
    • Перевод можно оставить пустым — «захвати сейчас, переведи вечером» — это нормальный сценарий.
    • Дубликаты расширение ловит само и предлагает «Добавить всё равно».

    Включаем ИИ-перевод (бесплатно)

    Из коробки переводит Google. Но вся магия — словарные формы, формы глаголов, перевод по контексту, примеры — включается с ИИ-движком. Ключ Gemini бесплатный:

    1. Зайди на aistudio.google.com/apikey (вход обычным Google-аккаунтом) → Create API key → скопируй ключ. Карта не нужна.
    2. Попап расширения → секция «Перевод» → «Движок перевода» → ИИ.
    3. Провайдер: Google Gemini → вставь ключ → кнопка «Проверить ИИ» → должно показать зелёную галочку с примером.
    4. По желанию включи «Пример-предложение на карточку» и озвучку (секция «Карточки» → язык TTS).

    Также поддерживаются OpenRouter, OpenAI и локальная Ollama (совсем без ключа) — пресеты уже внутри. В поле «Свои инструкции для ИИ» можно по-русски дописать свои правила — например, «добавляй управление глагола с падежом».

    Уровень и язык: в той же секции укажи свой уровень (A1–C2) — ИИ подстроит перевод и подсказки, и язык, на который переводить (по умолчанию русский).

    💡 Бесплатный лимит Gemini считается на каждую модель отдельно. Если увидишь «ИИ не сработал (лимит)» — впиши в поле «Модель» gemini-2.5-flash-lite (у неё самый щедрый лимит) или подожди сброса квоты.

    Частые вопросы

    Кнопка не появляется

    Проверь, что Anki запущен, и обнови страницу (F5) после установки расширения. На системных страницах Chrome, в Google Docs и во встроенном PDF-просмотрщике кнопка не работает — это ограничение браузера (в PDF выручает ПКМ → «Добавить мгновенно»).

    Карточки не появляются на телефоне

    Они появятся после синхронизации: Anki Desktop → Sync (нужен бесплатный аккаунт AnkiWeb) → синхронизация в AnkiDroid/AnkiMobile.

    Это безопасно?

    Код открыт: github.com/ArtCog/anki-word-clipper. Расширение общается только с локальным Anki и с выбранным тобой переводчиком. Ни аналитики, ни аккаунтов, ни облака.

    Firefox?

    Поддерживается как временное расширение: about:debugging → Load Temporary Add-on → manifest.json. Подробности в README на GitHub.
